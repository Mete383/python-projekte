# 🎡 Developer Playground

Welcome to my personal coding sandbox! This folder serves as a digital notebook where I experiment with core algorithmic logic, practice foundational syntax, and solve targeted engineering riddles.

## 🎯 Purpose
Before building full-scale machine learning systems, a developer needs to master the fundamentals. The scripts here document my journey through algorithm design, state management, and early statistical modeling.

## 🧪 Highlights inside this Folder
* **Foundational Math & ML:** Deep-dives into early data structures and baseline modeling concepts (like `auto_tabelle.py`).
* **Utility Tools:** Lightweight Python applications designed to solve real-world tasks, manage state, and structure logical flows (such as `passwort_manager.py` and `tip_calculator.py`).
* **Logic & Conditionals:** Practice scripts focused on control flow, data lists (`pizza_liste.py`), and mathematical search routines (`max_wert_suchen.py`).

## ⚙️ Core Concepts Explored
* Python Object Types & Methods (Dictionaries, Lists, Tuples)
* Input sanitization and conditional branching (`if/elif/else`)
* File writing, loop mechanics (`while`/`for`), and logic testing
